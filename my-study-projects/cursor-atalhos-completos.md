## ✏️ EDIÇÃO RÁPIDA

### **Comentários**
- `Ctrl + /` - **Comentar/descomentar linha**
- `Shift + Alt + A` - Comentar bloco

### **Seleção Inteligente**
- `Ctrl + D` - **Selecionar próxima ocorrência**
- `Ctrl + Shift + L` - **Selecionar todas as ocorrências**
- `Ctrl + U` - Desfazer última seleção
- `Ctrl + Shift + U` - Expandir seleção

### **Manipulação de Linhas**
- `Alt + ↑/↓` - **Mover linha para cima/baixo**
- `Shift + Alt + ↑/↓` - **Duplicar linha**
- `Ctrl + Shift + K` - **Deletar linha**

- `Alt + Click` - Adicionar cursor

## ⚙️ CONFIGURAÇÕES IMPORTANTES

### **Auto-save**
- `Ctrl + Shift + P` → "Preferences: Toggle Auto Save"
- `Ctrl + ,` → Abrir configurações

### **Format on Save**
```json
{
    "editor.formatOnSave": true,
    "editor.formatOnType": true,
    "java.format.enabled": true,
    "java.format.onType.enabled": true
}
```

### **Java Settings**
```json
{
    "java.home": "path/to/jdk",
    "java.configuration.updateBuildConfiguration": "automatic",
    "java.compile.nullAnalysis.mode": "automatic"
}
```

### **Cursor AI Settings**
```json
{
    "cursor.chat.enabled": true,
    "cursor.codeGeneration.enabled": true,
    "cursor.inlineChat.enabled": true
}
```

## 💡 DICAS PRO

### **Produtividade**
- **Use `Ctrl + Shift + P`** para descobrir novos comandos
- **Configure atalhos personalizados** para suas ações mais frequentes
- **Use snippets** para código repetitivo
- **Aproveite o AI** para documentação e debugging

### **Java Específico**
- **Habilite format on save** para manter código limpo

- **Configure Maven** para builds automáticos
- **Use Spring Boot DevTools** para hot reload

- **Use conditional breakpoints** para casos específicos
- **Configure logpoints** para logging sem parar execução
- **Use watch expressions** para monitorar variáveis
- **Configure exception breakpoints** para capturar erros
